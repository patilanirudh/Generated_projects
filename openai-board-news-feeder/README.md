# openai-board-news-feeder
A CLI tool that fetches and prints news articles about OpenAI's board leadership changes to US users.

## Installation
To install, run `pip install -r requirements.txt` in your terminal.

## Usage
```bash
python main.py
```
This will print the latest news article about OpenAI's board leadership changes to US users.

## Requirements
- Python 3.8+
- argparse
- requests

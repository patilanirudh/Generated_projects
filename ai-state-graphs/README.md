# ai-state-graphs
A Flask application that generates graphs explaining the state of AI in 2026 for US users.

## Description
This project aims to provide a visual representation of AI trends and advancements in 2026, helping users understand the current state of AI in the United States.

## Setup Instructions
1. Clone the repository: `git clone https://github.com/your-username/ai-state-graphs.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `python app.py`

## Usage Examples
To view a graph, navigate to `http://localhost:5000` in your web browser.

### API Endpoints

* GET `/graphs`: Returns a list of available graphs.
* GET `/graphs/:graph_id`: Returns a specific graph.

## Limitations
This application is designed for demonstration purposes only and may not be suitable for production use without further development and testing.
